# Summer Grade 11 Prep

Мета: за 8 тижнів літа повторити й підтягнути:

- математику 5–10 класів;
- хімію;
- українську мову;
- історію України;
- підготуватися до 11 класу без паніки у вересні.

## Головне правило

Кожного дня мінімум:

- 30 хв математики;
- 10 хв повторення формул, дат або правил.

Краще маленький стабільний прогрес, ніж 8 годин навчання один день і потім тиждень нічого.

## Структура тижня

| День | Предмети |
|---|---|
| Понеділок | Математика + українська мова |
| Вівторок | Математика + хімія |
| Середа | Математика + історія України |
| Четвер | Математика + українська мова |
| П’ятниця | Математика + хімія |
| Субота | Математика + історія України |
| Неділя | Повторення, мінітест, виправлення помилок |

## Прогрес

- [ ] Тиждень 1 — база 5–6 класу
- [ ] Тиждень 2 — 7 клас
- [ ] Тиждень 3 — 8 клас
- [ ] Тиждень 4 — 9 клас
- [ ] Тиждень 5 — 10 клас, тригонометрія, похідна, ХХ століття
- [ ] Тиждень 6 — поглиблення 10 класу, 1920–1930-ті
- [ ] Тиждень 7 — велике повторення
- [ ] Тиждень 8 — фінальне закріплення

## Як навчатися

1. Відкрий `roadmap-by-topics.md`.
2. Обери тему, яка йде першою у твоєму предметі.
3. Знайди урок у `learning-links.md`.
4. Подивись пояснення або прочитай параграф.
5. Зроби вправи.
6. Помилки запиши у файл `mistakes.md` відповідного предмета.
7. Наприкінці дня онови `progress.md`.
