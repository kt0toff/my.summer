# Математика — формули

## Дроби

- Щоб додати дроби з різними знаменниками, треба звести їх до спільного знаменника.
- Щоб помножити дроби, множимо чисельник на чисельник, знаменник на знаменник.
- Щоб поділити на дріб, множимо на обернений дріб.

## Відсотки

- 1% = 0,01
- Щоб знайти відсоток від числа: число × відсоток / 100.
- Щоб знайти число за його відсотком: частина × 100 / відсоток.

## Квадратне рівняння

ax² + bx + c = 0

D = b² - 4ac

x₁ = (-b + √D) / 2a  
x₂ = (-b - √D) / 2a

## Теорема Вієта

Для x² + px + q = 0:

x₁ + x₂ = -p  
x₁ · x₂ = q

## Похідна

- (xⁿ)' = n·xⁿ⁻¹
- (c)' = 0
- (kx)' = k
- (u + v)' = u' + v'
