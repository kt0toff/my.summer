# Як запустити сайт

Це невеликий сайт для літнього навчання з сервером, SQLite базою даних, progress bar, списком тем і мінітестами.

## 1. Встанови Node.js

Потрібен Node.js версії 18 або новіший.

Перевірка:

```bash
node -v
npm -v
```

## 2. Склонуй репозиторій

```bash
git clone https://github.com/kt0toff/my.summer.git
cd my.summer
```

## 3. Встанови залежності

```bash
npm install
```

## 4. Запусти сервер

```bash
npm start
```

Після запуску сайт буде тут:

```text
http://localhost:3000
```

База даних створиться автоматично:

```text
data/study.db
```

## 5. Запуск через ngrok

В іншому терміналі запусти:

```bash
ngrok http 3000
```

ngrok дасть посилання типу:

```text
https://example-name.ngrok-free.app
```

Відкрий його в браузері — сайт буде доступний через інтернет.

## Що є на сайті

- гарний dashboard;
- progress bar;
- додавання тем до вивчення;
- статуси тем: план, в роботі, готово;
- мінітести;
- SQLite база даних;
- швидкі переходи до підручників і roadmap.

## Корисні команди

Запуск:

```bash
npm start
```

Перезапуск після змін:

```bash
Ctrl + C
npm start
```

Якщо треба очистити базу:

```bash
rm -rf data/study.db
npm start
```

Після цього база створиться заново з початковими темами і тестами.
